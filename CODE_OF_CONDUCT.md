# Code of Conduct

This project adopts the [CNCF Code of Conduct][cncf] as its standard of behaviour. **zopa is not a CNCF project** — the text is reused because it is a good one, not because there is any affiliation.

That distinction matters for reporting. The CNCF conduct committee handles reports for CNCF projects and has no relationship with this one, so `conduct@cncf.io` is not a route to anyone who can act here. Reports go to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md); contact them through the GitHub profile linked there, which is the only private channel this project has. [GOVERNANCE.md](GOVERNANCE.md) covers how maintainers handle private matters.

If zopa ever does join a foundation, this file changes and reporting moves with it.

[cncf]: https://github.com/cncf/foundation/blob/main/code-of-conduct.md
